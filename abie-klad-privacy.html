Политика конфиденциальности «Abie Склад»

Дата последнего обновления: 11 октября 2026 г.

1. Кто публикует приложение и кто обрабатывает данные

Приложение «Abie Склад» для iOS публикует частное лицо — независимый разработчик. Приложение распространяется бесплатно, не показывает рекламу и не содержит встроенных покупок.

«Abie Склад» — рабочее место торгового представителя: приложение получает от учётной системы организации справочники (клиенты, товары, остатки, цены) и отправляет в неё заказы. Учётные данные для подключения выдаёт администратор организации. Регистрации в приложении нет.

У приложения нет собственного сервера. При первом запуске пользователь указывает адрес сервера обмена своей организации, логин, пароль и профиль. Все данные передаются только между устройством и этим сервером. Оператором персональных данных выступает организация, которая обслуживает сервер обмена и учётную систему. Разработчик приложения не имеет доступа ни к серверу, ни к передаваемым данным.

Приложение не использует сторонние сервисы аналитики, сбора сбоев, рекламы и уведомлений. Данные не проходят через инфраструктуру разработчика.

2. Какие данные обрабатываются и зачем

  • Параметры подключения: адрес сервера обмена, логин, пароль и профиль (папка обмена). Нужны для обмена с сервером организации. Передаются только на этот сервер.
  • Идентификатор установки: случайный идентификатор, который приложение создаёт при первом запуске. Передаётся на сервер организации вместе с запросами, чтобы сервер отличал устройства. С личностью пользователя и рекламными идентификаторами не связан.
  • Справочники организации: клиенты (названия, адреса, примечания, сведения о задолженности), организации, виды оплаты, товары, остатки и цены складов. Приложение получает их с сервера организации, чтобы торговый представитель мог оформлять заказы и видеть долги клиентов.
  • Заказы: клиент, организация, вид оплаты, склад, позиции и количество, скидки и наценки, стоимость и дата доставки, комментарий. Передаются на сервер организации для обработки в учётной системе.

Приложение не запрашивает доступ к камере, микрофону, фотографиям, контактам, местоположению и уведомлениям. Рекламных сетей и трекеров в приложении нет, рекламный идентификатор устройства не используется.

3. Где хранятся данные

Справочники и заказы хранятся на сервере организации и в её учётной системе. Разработчик приложения доступа к ним не имеет.

На устройстве хранятся:

  • копия справочников организации — для работы без связи и быстрого поиска;
  • заказы в очереди на отправку и копии отправленных заказов (архив за последние 7 дней);
  • пароль — в защищённом хранилище iOS (Keychain), остальные параметры подключения — в настройках приложения.

Схему подключения (HTTPS или HTTP) пользователь выбирает при вводе адреса сервера в соответствии с настройкой сервера организации. При подключении по HTTP данные передаются без шифрования. Рекомендуется использовать HTTPS, если сервер организации его поддерживает.

4. Передача данных третьим лицам

Приложение передаёт данные только на сервер обмена, адрес которого указал пользователь. Данные не продаются и не передаются третьим лицам. Внутри организации данные доступны в соответствии с правилами самой организации.

5. Срок хранения

Справочники и заказы на сервере и в учётной системе хранятся столько, сколько определяет организация как оператор данных. На устройстве копии отправленных заказов удаляются через 7 дней. Справочники обновляются при каждом получении данных и очищаются при смене профиля.

6. Права пользователя и удаление данных

Учётные записи для обмена создаёт и удаляет организация. Запросы о доступе к данным, их исправлении или удалении на сервере подаются оператору — через администратора организации.

Все данные приложения на устройстве, включая пароль, справочники и заказы, удаляются вместе с приложением.

7. Изменение Политики

Актуальная редакция Политики публикуется на этой странице. Ссылка на неё есть в приложении: «Настройки» → «О программе».
